# 격리 계산 코드 보관소

- `runs/YYYYMMDD/<실행ID>/`: 매 실행의 원본 코드, 입력, 결과, 오류, SHA-256 메타데이터
- `library/<등록ID>/`: 사용자가 검토하고 정식 등록한 불변 버전과 사용 이력
- 동일 코드가 3회 이상 성공하면 화면에 `정식 등록 검토 권장`으로 표시한다.
- 추천은 자동 등록이 아니다. 사용자가 코드를 검토·수정하고 등록해야 한다.
- 등록 코드도 실행할 때마다 새 `runs` 폴더에서 격리 실행한다.
- 이 폴더의 코드는 Stock 메인 프로그램에 자동 편입되지 않는다.
- import 및 파일·네트워크·DB·내부 속성 접근은 허용하지 않는다.
